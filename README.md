# Коллегия адвокатов «Перспектива»

Демонстрационная версия сайта для Самары и Самарской области.

Сайт: https://hook-atelier.github.io/perspektiva/

30 страниц, скролл-видео песочных часов и Фемиды, интерактивные практики. Форма не отправляет заявки; данные коллегии заполняются после согласования. Поисковая индексация демонстрации отключена.

В репозитории только готовые публичные файлы сайта. Внутренние документы, анкеты и материалы разработки не публикуются.
